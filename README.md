# 🌐 DIGITAL HISTORY

The interactive museum of computing, programming, the internet and the future.

## 📋 Overview

Digital History is a complete, production-ready web application that serves as an interactive digital museum. It chronicles the evolution of computing, programming languages, the internet, cybersecurity, and artificial intelligence.

## ✨ Features

### 🏛️ Museum Experience
- Interactive timeline from 1800 to the future
- Virtual museum with themed rooms
- Technology encyclopedia
- Famous people directory
- Retro internet experience

### 🎮 Interactive Learning
- Digital Lab with simulators (DNS, HTTP, Binary, ASCII)
- Educational games and quizzes
- Code playground
- Binary converter
- Encryption visualizer

### 👤 User Features
- User registration and login
- Achievement system
- Favorites and saved content
- Quiz scores and progress tracking
- Personalized experience

### 🌍 Localization
- Full bilingual support (English & Arabic)
- RTL support for Arabic
- Easy language switching
- Extensible for more languages

### 🔒 Security
- CSRF protection
- SQL injection prevention (PDO)
- XSS protection
- Password hashing (bcrypt)
- Session security
- Rate limiting
- Secure file uploads

### 📱 Responsive
- Desktop
- Laptop
- Tablet
- Mobile
- Touch-friendly interface

## 🚀 Quick Start

### Requirements
- PHP 8.0+
- MySQL 5.7+
- Apache/Nginx with mod_rewrite
- Composer (optional)

### Installation

1. **Clone or download** to your web server directory

2. **Create database**:
```bash
mysql -u root -p -e "CREATE DATABASE digital_history CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;"
